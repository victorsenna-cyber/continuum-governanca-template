# 70-metodologias-chave — biblioteca de referência

PDFs e livros de terceiros que fundamentam métodos da casa (Receita Previsível, Blitzscaling, Hormozi, Brunson, Rackham, PNL, Onboarding Orquestrado e o que a sua operação adotar). **Ficam fora do git** (`.gitignore`: `*.pdf`, `*.epub`, `*.mobi`) por direito autoral; a pasta existe para que os rodapés "Base:" dos métodos tenham para onde apontar.

Regra: livro é proveniência, não carga. Um método que depende de um livro para ser executado não está pronto; o que importa dele já foi destilado para `100-métodos/`.
