# Sessões do Claude da casa (operação, não de conta)

Transcrito em Markdown de sessões do Claude Code que decidem algo da casa, gerado por `../ferramentas/exportar-sessao.py`. Uma sessão por arquivo, com data, assunto e o id do `.jsonl`. Ficam as falas e as ferramentas usadas; os resultados de ferramenta e o raciocínio ficam de fora.

Sessão de conta vai para a pasta do cliente (`clientes/<cliente>/NN - registros e arquivo/sessoes-claude/`). O transcrito é proveniência: a decisão vale onde foi registrada (`STATUS.md`, proposta, fila).
