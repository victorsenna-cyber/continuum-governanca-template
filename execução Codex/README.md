# execução Codex — a antessala

> **O que é:** a única pasta onde um **executor externo** (um segundo agente — nos métodos, "Codex") escreve. O que está aqui é **proposta**, nunca estado, até ser promovido ao canônico pelo `40-operacao-rotinas/RITO-INTEGRACAO-CODEX.md` (gate de cinco itens).
> **Índice obrigatório:** `STATUS-CODEX.md` — pacote fechado sem linha lá é pacote perdido.
> **Por conta:** `clientes/<cliente>/execução Codex/`, com o mesmo contrato.
> **Se a operação não usa segundo agente:** a pasta fica vazia e nada muda. A arquitetura existe para quando usar.

Estrutura de um pacote: `<area>/<slug-data>/` com o entregável, um `LEIA-ME.md` (o que é, de que pedido veio, o que falta) e a linha correspondente no `STATUS-CODEX.md` §2.
