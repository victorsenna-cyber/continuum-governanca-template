# 80-juridico/registros — um arquivo por caso

Casos, conflitos e exposições jurídicas. **Um arquivo por caso**, nomeado `AAAA-MM-caso-<slug>.md`, no padrão das **quatro camadas** do `CLAUDE.md` §11.1: fatos e números · decisões e o descartado · tom e conduta · mensagens literais com data e hora. Template de abertura na skill `10-skills/juridico/blue-team.skill.md`.

Mensagens trocadas (WhatsApp, e-mail) entram como `MSG-<parte>-<data>.md`, literais. Áudio recebido é transcrito ao lado (`METODO-TRANSCRICAO-DE-AUDIO.md`). Comprovantes ficam numa subpasta por caso.

**Teste de suficiência antes de fechar um registro (§11.4):** outra IA, abrindo só este arquivo, escreveria a próxima mensagem no tom certo e sem repetir erro nosso?
