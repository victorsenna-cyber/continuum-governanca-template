# _modelo — o esqueleto de uma conta

Copie esta pasta para `clientes/<Cliente>/` e renomeie. Depois, copie `90-templates/conta-nova/PAINEL.md` e `PEDIDO-UNICO.md` para dentro, e `90-templates/lexico-icp/` no onboarding (nunca na primeira peça).

Pastas a criar na conta, na sequência que ela precisar (o número é dela):

```
01 - contexto/           (sempre; recebe gravação, transcrição, material recebido; OpenWA/ se houver captura)
02 - <próxima área>/     (criativos, tráfego pago, web design, branding, registros e arquivo…)
execução Codex/          (só se houver executor externo)
```

Arquivos que nascem vazios no dia 0: `STATUS.md` (com a linha de abertura e as seções §1 snapshot · §2 pendências · §3 registros, entradas no topo), `DECISOES.md` (cabeçalho `| ID | Data | Decisão | Descartado | Por quê |`). `PILARES.md` nasce pelo `METODO-TESTE-DE-PILARES.md` no ato II do trilho.

Não copie este README para a conta.
