## 1. O QUE É, E O QUE NUNCA É

> **Benchmarking é leitura de evidência.** O mercado já gastou dinheiro descobrindo o que funciona e deixou o resultado exposto. **Nós lemos esse resultado antes de gastar o nosso.**

| É | NÃO é |
|---|---|
| extrair **padrão** — ordem, dose, proporção, categoria de argumento | copiar texto |
| **medir** em que degrau o mercado está | assumir que o degrau atual é o certo |
| descobrir o que **já foi validado por dinheiro alheio** | validar a nossa hipótese |
| mapear **o que ninguém está dizendo** | escolher o concorrente mais bonito |

### 1.1 🔴 As três travas permanentes

1. **Não se reproduz copy alheia.** Extrai-se estrutura, dose e categoria. O texto é sempre nosso — **por método e porque copy publicada é obra de terceiro.** Trecho literal entra só como âncora curta de análise, entre aspas e com fonte.
2. **Fala de concorrente é grau `R` (relatada) ou `I` (inferida), jamais `D` (direta).** É o que o concorrente *acha* que a dor é (`METODO-ARQUEOLOGIA-DE-ICP.md`).
3. **Benchmark informa, não decide.** Quem decide é o teste de pilares e **nós** — a estrutura é alçada nossa (`METODO-ALCADA-DE-ESTRUTURA.md` · `CLAUDE.md` §8, REGRA Nº 0). ~~e o dono da oferta~~ **O dono da oferta entra com objeção de congruência**, não com escolha de estrutura.

> ⭐ **A régua que sintetiza as três: ESTRUTURA SE MODELA, CENA SE COLHE.** A peça alheia diz **em que ordem as objeções morrem.** Ela nunca diz o que o nosso público sente.

> ⚠️ **A régua da linha do orgânico** *(08/10/2026, fonte: destilação de criativos de um educador público de tráfego e VSL)*: **viral prova atenção, não prova que paga mídia.** Tema que viralizou entra como **exploração** — nos 30% do portfólio (`METODO-TRAFEGO-PAGO.md` §4.2), declarado como teste — e **nunca como base de promessa** (`METODO-DIRECT-RESPONSE.md` §2-bis). Os dois casos da fonte só viraram evidência quando uma VSL **escalou** com o tema. **Dois usos válidos:** construir o mecanismo em torno do tema, ou usá-lo como gancho e **transicionar** para o mecanismo real ("X funciona? sim, mas existe algo mais forte"). 🔴 **E comentário viral não é fala do nosso público:** do orgânico sai tema e formato, **nunca léxico de grau `D`.**

### 3.3 O teto, e o que fazer quando não dá

**Teto: 3 referências.** Mais não aumenta precisão — aumenta indecisão.

**Quando não há 3 no nicho** (cenário provável em serviço B2B), **o gate não afrouxa. Muda de fonte, e a mudança se declara:**

| Saída | O que registrar |
|---|---|
| **Nicho adjacente** | qual, e **por que é adjacente** — mesmo tipo de decisão de compra, mesmo nível de ticket, ou mesma estrutura de objeção |
| **Fonte secundária** | qual, e **que confiabilidade se perde** |
| **Outro formato** | ex.: não há VSL, mas há página longa vendendo — a estrutura de argumento transfere, a de mídia não |

🔴 **O que não se faz: seguir com uma referência e chamar isso de benchmark.** Uma peça é anedota; três é padrão.

### 5.4 🔴 A ordem, que é o achado principal

**Contar sem registrar a ordem perde o essencial.** Para cada bloco, a **sequência** dos elementos:

```
LEAD:      gancho → promessa → segmentação → depoimento → curiosidade
HISTÓRIA:  credencial → história → objeção
MECANISMO: ponto-lógico ×5 → reason-why → apelido → número
CONSTRUÇÃO: história → número → depoimento → transição
OFERTA:    oferta → benefício → exclusão → descrição → ancoragem → preço → cta → garantia → bônus → recapitulação → dois-caminhos
```

> **Por que a ordem é a tecnologia:** nicho se define por desejo comum; desejo comum produz **as mesmas objeções, na mesma sequência.** Matar objeções na ordem validada funciona independentemente das palavras — **por isso a ordem se reutiliza e o texto não.**

### 5.5 Como a contagem vira decisão

| Se a referência tem | A nossa tem |
|---|---|
| mecanismo de 1.800 palavras | **~1.800**, não 3.000 |
| 6 pontos lógicos | 5 a 7 |
| razão prova/promessa de 2:1 | próximo de 2:1 |
| primeira prova aos 150 palavras | prova cedo, não no meio |
| lead de 12% do total | lead curta |

🔴 **Peça fora de escala falha antes de o conteúdo ser julgado.** É o erro mais previsível do método inteiro: modelar a estrutura e ignorar a dose.

### 7.2 Densidade competitiva

**Quantos players ocupam o mesmo degrau com o mesmo mecanismo.** A biblioteca de anúncios responde. **Degrau lotado é degrau onde só o preço compete.**

### 7.3 ⭐ O espaço vazio — a dimensão que produz vantagem

**Preencher as 14 primeiras dimensões produz uma peça que é a média do mercado: competente e indistinguível.** O valor está na leitura negativa.

| Dimensão | As três dizem | **Ninguém diz** |
|---|---|---|
| Promessa | | |
| Mecanismo | | |
| Prova | | |
| Objeção endereçada | | |
| Segmentação | | |
| Formato | | |

> **Três concorrentes fortes convergindo no mesmo argumento significa que o argumento oposto está livre — e que ninguém testou por medo, não por evidência.**

#### 🔴 Teste de discriminação — evidência ou eco?

**Convergência tem duas causas, e elas valem coisas muito diferentes:**

| Causa | Como identificar | Quanto vale |
|---|---|---|
| **Evidência** | os três têm histórico próprio de teste | padrão forte |
| **Eco** | a referência mais antiga é a única com dado próprio; as outras entraram depois | 🔴 **vale um terço do que parece** |

⚠️ **E a ressalva que impede o entusiasmo: espaço vazio às vezes está vazio porque não funciona.** Gera **hipótese, nunca conclusão** — e a hipótese entra como **uma das leads de teste**, jamais como estrutura principal.

🔴 **Reforçado em 22/09 pela REGRA DA ESCALA** (`METODO-DIRECT-RESPONSE.md` §2-bis): **a estrutura principal — promessa, oferta, lead, arquitetura — vem do escalado.** O espaço vazio só pode morar em duas coisas: **no mecanismo e no apelido**, que é onde a diferenciação pertence (*"a promessa se modela, o mecanismo se diferencia"*), **ou num ângulo lateral de teste, declarado como tal.** Caso real em que isso foi violado: uma consolidação de benchmark de conta (22/09), que tratou o espaço vazio como vantagem da estrutura.

| **O que fica de estudo?** | as outras duas — para dor, oferta e ângulo alternativo |
| **Qual a hipótese do espaço vazio?** | → vira uma das leads de teste |

> **Modelar não é copiar.** Modela-se a **sequência e a dose**; o conteúdo é próprio. **Diferencial próprio entra** — bônus melhor, posicionamento melhor, garantia melhor. **A estrutura é que se preserva.**
